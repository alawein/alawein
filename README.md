# Meshal Alawein

I build evidence-first scientific software and AI systems whose claims can be checked.

Computational physicist turned AI systems engineer. PhD, EECS, UC Berkeley. Founder of [Kohyr](https://kohyr.ai). 12 years in scientific computing; 6+ in ML/AI.

I build at the intersection of physics, machine learning, and auditable software, from micromagnetic simulators and quantum transport frameworks to LLM evaluation and agent-action verification.
