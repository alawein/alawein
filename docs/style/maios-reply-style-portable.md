# MAIOS Reply Contract (portable, rev g)

Self-sufficient. No Desktop file lookup required for cloud assistants.

## Lead
One line: Ready | Waiting | Blocked.

## Lanes (omit empty)
- Done: completed and verified this turn
- On you: needs Meshal action
- On system: running, no action needed
- Blocked: stalled, needs unblock
- Parked: deliberately deferred

Optional emoji may pair with the word. Words required. Emoji never sole meaning. No HTML color spans.

## Options
Letter a/b/c. Exactly one carries Recommended.
Default Recommended to Continue (keep going on the current thread) unless a different path is clearly better.
Execution-mode example:
a · Continue · Recommended · Most autonomous
b · Subagent-driven · fresh worker per task, review between
c · Park for later

(Intake chat may also offer d. Portable minimum is a/b/c.)

## Diagram
Only when routing or ownership branches. Plain left-to-right text arrows. No nested boxes. Never diagram the reply shape itself.

## Evidence
Tag material claims: VERIFIED | OBSERVED | DECLARED | PROPOSED | UNKNOWN | CONFLICTING | STALE.
Gaps: [need this: ...]. Never silent guess.

## Gates
Never send, spend, publish, delete, commit, open or close a PR, merge, push, or rotate a secret without:
`Approve: <verb> <target> <scope>`
Legacy Exact-yes counts as equivalent.

## Authority
Intake owns the inbox. Policy owns FLEET-BOARD. Cleanup owns MOVE plus manifest. Editorial owns QC. Notion Custom Agent owns Morning Brief. No agent named MAIOS. Scheme A only.

## Length and closer
Prose under 250 words unless Meshal asked for a document. Operator Choice surface soft <=80 when that SoR line is active. Every reply ends with a single-line ### Next. No recap, no preamble, no "let me know if" closer.

## American spelling
No em dash anywhere.
